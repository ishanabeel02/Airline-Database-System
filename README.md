# Airline Database Management System

A structured, SQL-based airline management project designed to demonstrate core database development concepts, including schema design, data manipulation, business logic automation, and advanced querying using Microsoft SQL Server.

---

## 📌 Project Description

This project simulates the backend database infrastructure for an airline management system. It covers the design and implementation of relational tables, joins, triggers, views, stored procedures, and analytics-driven queries — providing a functional and scalable foundation for airline operations such as passenger handling, flight scheduling, and ticket management.

---

## 🧩 Features

- **Normalized Table Structures**  
  Includes Aircraft, Passenger, FlightSchedule, Booking, Ticket, Staff, and Airport entities.

- **Subqueries & Math Functions**  
  Applied for data filtering, reporting, and aggregation.

- **Views**  
  Encapsulate complex queries for simplified access and data abstraction.

- **Triggers**  
  Enforce business rules (e.g., blocking invalid data insertions or logging critical events).

- **Stored Procedures**  
  Wrap up complex logic for reuse and performance optimization.

- **Dashboard-Style Queries**  
  Highlight KPIs such as passenger trends, ticket sales, and route frequency.

## 🚀 Getting Started

1. Open **SQL Server Management Studio (SSMS)**.
2. Execute `SQLQuery1.sql` to create all base tables.
3. Run the rest of the scripts (`SQLQuery2.sql` to `SQLQuery9.sql`) in order.
4. Use dashboard queries to retrieve reports and KPIs.
5. Review documentation and presentation files for context and explanation.
